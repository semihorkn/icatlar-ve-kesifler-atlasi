# İcatlar ve Keşifler Atlası

iotfyedu için hazırlanmış Türkçe, etkileşimli 3B icatlar ve keşifler atlası.

## Yayın

`main` dalına gönderilen her değişiklik `.github/workflows/pages.yml` üzerinden GitHub Pages'e otomatik yayımlanır.

## Güvenlik

- Uygulama tamamen statiktir; sunucu, veritabanı, giriş veya gizli anahtar içermez.
- Üçüncü taraf 3B görüntüleyici proje içinde sabitlenmiş olarak tutulur.
- İçerik Güvenliği Politikası (CSP) yalnızca aynı kaynaktan yüklemeye izin verir.
